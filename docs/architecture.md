# Архитектура — публичное резюме ТЗ v1.2

Оригинальное ТЗ и референсы хранятся отдельно. Здесь только согласованное публичное резюме; детали и открытые вопросы не подменяются догадками. Главная задача: #1.

Модульный монолит NestJS + Fastify, REST /api/v1, OpenAPI, Orval, SSE; PostgreSQL + Prisma, SQL-ограничения резервирования, pg-boss, SeaweedFS, Better Auth, Pino. Веб-кабинеты и глобальная админка — Next.js, единый shadcn/ui, Tailwind, Lucide, TanStack Query/Table, React Hook Form, Zod, FullCalendar Standard, Recharts, Sonner, date-fns, next-intl. Telegram — grammY, menu, conversations, i18n. Экспорт ExcelJS. Тесты Vitest, Testcontainers, Playwright, Storybook, k6. Docker Compose на собственном сервере; без Caddy, Redis/BullMQ, Google Sheets, готовых админ-шаблонов и платных UI-расширений.

## Границы

- apps/web, apps/admin, apps/api, apps/bot, apps/worker — независимые точки запуска, клиенты не обращаются к бизнес-таблицам напрямую.
- packages/config — общий конфигурационный фундамент; остальные packages/ui, database, contracts, client-api, auth, i18n, shared добавляются по мере появления реальной потребности.
- Компании изолированы; водитель может работать в нескольких компаниях, его календарь глобален. Конкурентный приём заявки и резервирование атомарны. Деньги — точные десятичные значения, события — UTC, график — локальное время объекта.
- Уведомления и фоновые задачи не блокируют основную операцию. Финансы компаний скрыты от глобального администратора. Монетизация выключена по умолчанию.
- Публичный лендинг, один бот и четыре роли. UI согласуется в браузере; новый визуальный ориентир — мягкие тёмные поверхности и компактная типографика, без копирования стороннего продукта. RU/EN, dark/light.

Полная физическая схема и API проектируются и проверяются по этапам, а не создаются заранее.

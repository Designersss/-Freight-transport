# Backend engineering

Прочитать movaro-architecture, соответствующие issue и существующие модули. Проверить версии по lockfile/manifest: базовый RD-03 использует NestJS 11.2.12, Fastify 5.12.8, Zod 4.1.12; актуальная рабочая ветка может отличаться. Не переносить Express middleware/Request/Response в Fastify без проверки совместимости.

- Feature-модули с явно объявленными импортами/экспортами; constructor DI и документированные lifecycle hooks. Не использовать service locator, глобальное состояние запроса или циклические импорты как стандарт.
- Контроллер принимает и валидирует вход, вызывает сервис, возвращает публичный DTO. Бизнес-правила и транзакции не размещать в контроллере/боте. Входные схемы Zod и серверная проверка не заменяются TypeScript.
- Явные варианты результата, строгие типы, проверка nullable/unknown; не обходить типизацию any или unsafe cast. Не дублировать DTO/контракт без причины. Не изобретать новую систему ошибок; использовать существующий безопасный формат.
- В конфигурации — валидированные переменные, ранняя проверка обязательных настроек, секреты вне Git. Отказ зависимости не выдавать за успех; liveness и readiness различать. Не запускать фоновые задачи в HTTP-запросе, если операция предназначена для worker.
- Для сетевых вызовов — конечные таймауты, контроль ошибок, ограниченный retry только для безопасных/идемпотентных операций. Для CPU-тяжёлой работы сначала измерение, не блокировать event loop.
- Учитывать порядок завершения процессов, release ресурсов и сигнал остановки. Структурированные логи без секретов; использовать movaro-devops для операционной части.
- Тесты: unit бизнес-правил; HTTP через существующий Fastify inject; интеграционные — настоящие PostgreSQL/worker/storage. Проверить ошибки, права и параллельность; расширить список тестов, если существующий script выбирает отдельные файлы.

Результат: работающий минимальный срез, ссылки на API закреплённых версий, тесты и список непроверенного. Источники: https://github.com/nestjs/agent-skills ; https://github.com/Kadajett/agent-nestjs-skills ; https://docs.nestjs.com/techniques/performance .

# Frontend engineering

Применять при изменении React, маршрутов, компонентов, API-клиента, форм и таблиц. Сначала AGENTS.md, DESIGN.md, docs/architecture.md, docs/design-system.md, актуальный issue, package.json и lockfile. Проверять документацию установленной версии, не переносить советы для иной версии React/Next.js автоматически.

- Сохранять границы apps/web, apps/admin, packages/ui, packages/i18n и типизированного клиента. Общая UI-библиотека не знает бизнес-ролей и API; бизнес-компоненты составляют её примитивы. Не создавать общий слой ради единственного вызова.
- Server Components по умолчанию там, где это поддерживает существующая архитектура; клиентская граница только для взаимодействий и браузерных API. Не переносить секреты или авторизацию в клиент. Проверять гидратацию, cookie темы и локали.
- Композиция и явные варианты вместо множества флагов; чистые вычисления, один источник состояния; не синхронизировать производное состояние через эффект. Использовать стабильные ключи, документированные хуки, строгие типы без any и небезопасных assertions.
- Переиспользовать shadcn/Radix, Lucide и токены. Официальный registry — после проверки совместимости, лицензии и lockfile. Не устанавливать второй набор примитивов. Нативная семантика внутри компонентов обязательна.
- Навигация через имеющийся next-intl Link; сообщения RU/EN в packages/i18n. Реальные бизнес-формы через согласованные RHF/Zod, таблицы через TanStack Table по необходимости, не вручную имитировать библиотеку. Не добавлять пакет без задачи и согласования.
- API: проверять актуальный контракт, обработку 401/403/409/422/5xx по реальным схемам, отмену/устаревшие запросы и повторные действия; не придумывать форматы ответа. Не кешировать данные одной компании для другой.
- Если затронуты общие примитивы, проверить web/admin/Storybook. Сложные изменения — movaro-testing, производительность — movaro-performance, результат — movaro-review.

Результат: список изменённых границ, использованных компонентов, документации версий и проверок. Не объявлять код готовым без фактических результатов.

# Accessibility

Целевой стандарт WCAG 2.2 AA. Читать DESIGN.md, действующие компоненты и docs/e2e.md. Автоматический axe покрывает лишь часть требований.

- Использовать нативную семантику, корректные landmarks и иерархию заголовков; кнопка для действия, ссылка для навигации. Интерактивные иконки имеют доступное имя; декоративные скрыты от assistive technology. ARIA только при необходимости и согласно паттерну.
- Клавиатура: логичный Tab/Shift+Tab, Enter/Space по типу контрола, Escape для закрываемых оверлеев, отсутствие ловушек. Диалог получает фокус и возвращает его при закрытии; модальность и фон соответствуют Radix/ARIA. Фокус виден, не закрыт sticky-элементом и не дублируется жирным кольцом.
- Контраст текста AA: 4.5:1 обычный, 3:1 крупный; 3:1 для значимой границы/индикатора интерфейса, где применимо. Проверять реальные пары цветов обеих тем; статус не только цветом. Не удалять focus-indicator ради минимализма.
- Поля: label, связанная ошибка, aria-invalid и aria-describedby; сообщения о динамических изменениях объявляются уместно, без лишних повторов. Не препятствовать вставке пароля и менеджерам паролей; проверять доступную аутентификацию.
- Проверить увеличение текста до 200%, reflow на ширине 320 CSS px, размеры интерактивных целей WCAG 2.2 (24×24 CSS px или применимые исключения), touch и длинные RU/EN строки. Для действительно двумерных таблиц/календарей допускается обоснованная прокрутка, но остальные элементы должны reflow.
- Учитывать prefers-reduced-motion и не прятать функцию за hover. Проверять скринридером ключевые сценарии (например VoiceOver/NVDA при наличии), фиксировать браузер/ОС. Не заявлять, что это выполнено, если окружение недоступно.
- Использовать уже существующий axe в Playwright, расширять тесты целевыми проверками. Ручная проверка не заменяется нулём нарушений axe.

Источники: https://www.w3.org/TR/WCAG22/ ; https://www.w3.org/WAI/ARIA/apg/ ; https://playwright.dev/docs/accessibility-testing .
Результат: находки с критерием, маршрутом, шагами и доказательством; отдельно непроверенное.
